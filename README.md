🎃 Sweet 16 de Méline — Halloween House Party

Petit site d’invitation créé pour les 16 ans de Méline, fêtés le soir d’Halloween.

Le site permet aux invités de consulter les informations de la soirée, découvrir les règles, profiter d’une ambiance sonore horrifique et surtout confirmer leur présence en ligne.

Règles de la soirée

Ambiance sonore horrifique activable par bouton

⚙️ Fonctionnement du RSVP

Le formulaire d’invitation est connecté à une Google Apps Script Web App.

Lorsqu’un invité répond :

le formulaire envoie les données à Google Apps Script ;

la réponse est enregistrée dans Google Sheets ;

les colonnes stockées sont :

Date | Prénom | Présence | Déguisement | Message

le compteur du site récupère le nombre de réponses Oui et Non.

Aucun compte Google n’est nécessaire pour répondre à l’invitation.
