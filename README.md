# Halloween Birthday Party 🎃

Petit site d'invitation d'anniversaire / Halloween, prévu pour GitHub Pages.

## Fichiers

- `index.html` : structure de la page
- `style.css` : design Halloween / responsive
- `script.js` : compte à rebours et formulaire

## Mise en ligne GitHub Pages

1. Créer un dépôt GitHub public.
2. Ajouter les 3 fichiers à la racine du dépôt.
3. Ouvrir **Settings > Pages**.
4. Dans **Build and deployment**, choisir **Deploy from a branch**.
5. Choisir la branche **main** et le dossier **/(root)**.
6. Enregistrer.

Le site sera ensuite disponible sur une adresse du type :

`https://TON-PSEUDO.github.io/NOM-DU-DEPOT/`
